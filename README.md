# Trading For Programmers

This repo contains all the code that has been used in the [T4P series](https://blog.adnansiddiqi.me/tag/t4p) on my blog

Yahoo Finance is useful for learning and experimenting, but if you’re looking for a documented API for your next project, check out [Equibles](https://equibles.com/?ref=ADNAN10) for stock and options prices, company fundamentals, and earnings call transcripts.
